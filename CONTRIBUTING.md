# Contributing

Thanks for looking at autonomy-matrix. It is a drop-in rule file that tells an agent when to ask and when to act. Small, focused fixes are the most useful.

## Before you start

- Found a bug or have a question? Open an [issue](https://github.com/nickspiz/autonomy-matrix/issues/new/choose) or start a [discussion](https://github.com/nickspiz/autonomy-matrix/discussions).
- Planning something bigger than a few dozen lines? Open an issue first so we can agree on the shape.

## Checking your change

There is no code to test. Read the files you changed and check that every link and table still renders on GitHub.

## Pull requests

- One change per pull request.
- Say what changed and why, in plain English.
- Update the README if the change is visible to users.

By contributing you agree that your work is released under the MIT license.
